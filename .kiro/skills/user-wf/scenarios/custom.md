# 场景：自定义模式

当无场景匹配时触发。

## 主 session 操作

1. 与用户交互收集以下信息：
   - **监控目标**：要监控什么。
   - **检查方式**：用什么命令或 API 检查（只读或读写）。
   - **匹配条件**：什么内容算匹配消息。
   - **轮询间隔**：秒数。
   - **通知内容**：匹配时要发送什么信息到主 session。
2. 将收集到的信息总结后向用户确认。
3. 确认后继续启动工作流（见 `SKILL.md` 流程第 4 步）。

## 工作流 prompt 要求

按用户确认的信息生成 prompt，包括监控目标、检查命令/API、匹配条件、轮询间隔和通知格式。
