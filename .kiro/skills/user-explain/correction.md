# 纠错：知识过时自查

触发：用户指出某条知识或原则已不适用、不成立或版本不对。在任何模式下自动执行，不需要用户调用。

## 步骤

1. 先纠正当前回答：承认并改正，不辩护。
2. 定位受影响的内容：回看本轮取材时读过的 `domain/` 条目，以及涉及工具与版本的场景表述。
3. 判断波及范围，依次检查三类：用户直接指出的那条；同一主题下的相邻条目；与被指出的那条依赖同一前提的条目。依据是各条目的"适用版本与环境"字段，以及核实日期较久且主题容易变化的条目。
4. 在回复里列出受影响的条目，并说明建议如何修订。
5. 修订只在用户明确提出后，按 `modes/learn.md` 执行。

## 约束

- 不自行修改 `domain/` 的任何条目。
- `static` 模式下只做第 1 步到第 4 步。
