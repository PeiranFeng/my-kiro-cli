# 用语

## 名词的来源

回复中的每个名词和术语，来源只能是三者之一：

1. 代码里的标识符。
2. 该领域通用的术语。
3. 用户本轮用过的词。

其余一律改成描述性短语，说明"做某事的那个东西"。

## 不直译

- 遇到英文概念，先还原成它表达的意思，再用中文里表达这个意思的常用说法。
- 判断是否常用：中文技术人员在交谈或中文技术文档中会这样说吗？拿不准时，用对该意思的完整描述代替。
- 替换后的说法必须保留原词承载的区分，使它与对立概念仍可分辨。
- 动词与搭配同样按中文习惯组织，不逐字对译。
- 保留英文原文的情形只有两种：它是代码里的标识符，或中文没有通行说法。后一种情形在首次出现时附一句意思。

## 引用必须自明

不使用需要读者另行查找才能理解的指针，如裸锚点、缩写、代词。每个引用在当前句给出足够上下文，使读者无需跳出当前回复即可理解。

## 一词一义

同一概念全文用同一个词，同一个词只指一个概念。
