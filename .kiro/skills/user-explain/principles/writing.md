# 写作原则

## 篇章结构

- 答案先行：第一句给出对用户问题的结论。
- 理由归组：同一层的理由取 2 到 4 条，互斥且合起来完整，每条理由下接依据。
- 读者缺背景时，开头按"情境、冲突、问题、答案"铺垫，铺垫只写读者缺的部分。
- 一个段落承担一个功能、表达一个点，段首句是中心句。
- 按读者提问的顺序组织，不按作者思考的顺序。
- 用数字和机制代替形容词。

## 句间关系

相邻两句必须存在下表中的一种关系，能说出是哪种；说不出就补上关系或删除该句。关系可以由顺序表达，不必都有连接词。

| 关系 | 读者读完获得 |
|---|---|
| 原因与结果 | 认识到前者导致后者 |
| 证据 | 因此更相信所述主张 |
| 背景 | 获得理解相邻句所需的情境 |
| 阐述 | 获得同一对象的更多细节 |
| 对比 | 看到两项在某个维度上的差异 |
| 让步 | 承认一个看似冲突的事实后，仍接受主张 |
| 条件 | 知道结论依赖哪个条件 |
| 手段与目的 | 知道做什么、为了什么 |
| 问题与解法 | 先认识问题，再接受对应的解法 |
| 重述与概括 | 以更短或另一种说法再确认一次 |
| 序列 | 按先后顺序理解 |
| 并列 | 把同级的项一起理解 |

## 句子

以下原则用于验收时发现并修改问题句，写作时不逐句套用。

- 主语写出角色，动词写出动作；把藏起动作的名词化改回动词。
- 主语之后尽快接动词，两者之间不插入长成分。
- 句首放读者已知的信息，句末放新信息和需要强调的内容。
- 同一段内各句的主语或话题保持一致。
- 判断句子是否过长，看可作强调的候选项是否多于强调位，不看字数。
- 肯定句优于否定句；删去无意义和重复的词。

## 格式

- 数学公式用纯文本符号，包裹在代码块中，积分、求和等用文字标注范围，不用 LaTeX。
