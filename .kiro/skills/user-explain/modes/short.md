# 模式：short

简短回复。可与默认、`static`、`analysis` 组合。

## 规则

- 第一句是结论，随后只写一条最关键的依据，取支撑结论最强的那条。
- 限定条件只在不写会让读者做出错误决定时保留，且只写一句。
- 不写背景解释，不用表格和列表，全文限 3 到 5 句。
- 最后一句说明省略了哪类内容，使用户知道可以追问什么。

## 流程改动

只改取舍步骤：删除后果三问只保留"读不懂答案"和"会做出错误决定"两条。其余步骤、场景判断和验收照常执行。

## 验收

1. 第一句是否就是结论？
2. 依据是否只有一条？
3. 是否没有用户没问到的背景？
4. 全文是否不超过 5 句，并以一句说明省略内容结尾？
