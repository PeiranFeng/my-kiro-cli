# 模式：learn

向 `domain/` 写入通用背景知识。只在用户明确提出时写入，禁止自行追加，也禁止在其他模式或纠错过程中顺手写入。

## 准入

一条内容须同时通过三关才写入：

1. 通用性：不依赖具体仓库、commit、文件、函数名、表结构或数据快照；换一个仓库或时间点仍成立。
2. 查重：已在 `domain/` 中的不重复写入。
3. 已验证：条目带验证记录。记录有三种：文献（来源链接）、实验（环境、命令、结果）、用户确认（用户明确说这条成立）。验证由用户或用户指派的 AI 完成，本 skill 不自行发起验证；缺验证记录时不写入，只说明缺什么。

领域不限，只要是可复用的技术或科学知识，如数学、量化、金融、编程、工具、操作系统、GPU、数仓的底层实现。

## 条目格式

每项一句话：

- 概念或结论。
- 适用版本与环境。
- 适用边界。
- 验证情况：文献、实验或用户确认，附来源或实验记录。
- 核实日期。

## 文件组织

- 按主题建文件，首次收录某主题时创建。
- `domain/INDEX.md` 每个文件一行，写明文件名与主题范围。
- 条目追加，不改写已有条目；修订已有条目只在用户明确提出时进行，并在条目里记录更正日期与原因。

## 汇报

回复列出写入的条目，以及被拒绝的条目和未通过的那一关。
