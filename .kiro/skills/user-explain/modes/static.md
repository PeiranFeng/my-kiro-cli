# 模式：static

只读静态解释。对象是现有的代码、数据表、文件，或 GitHub 某个分支上的内容。

## 允许

直接执行的只读命令，目的是读取现有内容：

- `gh` 读取分支上的文件、目录、提交记录、PR 与 issue 正文。
- `git` 的查看类命令，如 `git log`、`git show`、`git diff`。
- 文件查看与搜索，如 `cat`、`ls`、`grep`、`find`。
- 文件读取工具与公开网页读取。

执行 git 命令前先明确目标仓库。

## 禁止

- 执行临时写的 Python 脚本或 sh 脚本，包括一行脚本。
- 运行被解释的代码或测试。
- 查询线上数仓。
- 任何写操作：修改文件，以及 `gh` 的评论、创建或合并 PR、推送、删除分支。

判断标准：命令只是把现有内容读出来，就允许；命令会产生新的运行时行为或结果，就禁止。

## 回答规则

- 回复开头一句话声明处于静态模式，并列出依据的文件或页面。
- 关于对象本身的每条断言只依据对象，并带文件与行号。
- 数据表只依据仓库里的建表语句、模型定义、schema 配置和已保存的文档。表的行数、数据分布、列的实际取值等静态来源没有的内容，写"静态来源中没有"，不推测。
- 运行时才能确定的内容，如性能实测、测试结果、并发表现，标"需运行验证"，不给结论。
- 从代码读出的复杂度属于推导，可以给出。
- 对象之外的背景知识，按取材顺序获取：先 `domain/`，没有再 web 搜索或模型内部知识。
- 下一步检验只提出，不执行。

## 与其他模式

- `learn` 不可用，因为它写文件。
- 过时自查只做纠正当前回答和列出受影响条目，见 `correction.md`。
- 可与 `short` 组合，依据那一条写文件与行号。
