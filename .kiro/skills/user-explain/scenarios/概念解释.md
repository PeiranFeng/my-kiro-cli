# 场景：概念解释

## 判断

解释公式、原理、外部工具、金融或数学概念。

## 方法

- 先查 `domain/INDEX.md`，有相关条目先采用。
- 定义由所属类别加区别特征构成。
- 从读者已知的概念讲到新概念，每个新概念只依赖前文已出现的内容。
- 公式：先逐个说明符号的含义与取值范围，再说明为什么这样写，最后给边界情形和对应的业务含义。
- 说明它解决什么问题，没有它会怎样。

## 必答要素

- 定义。
- 它解决的问题。
- 与读者已知概念的关系。
- 公式类追加：符号说明、来源原理、边界情形、业务含义。

## 验收

- 每个新概念出现时，它依赖的概念已在前文出现。
- 公式中的符号全部有说明。
- 公式用纯文本，无 LaTeX。
- 没有把读者已掌握的内容再解释一遍。
