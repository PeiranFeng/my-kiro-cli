# 场景：严格推导

## 判断

结论可以由定义、代码或已知前提逐步推出：复杂度、数学性质、不变量、正确性论证。

## 方法

- 按"前提、推导、结论"排开，每一步标明依据：哪条前提、哪段代码、哪条定理。
- 先定义变量再使用，隐含前提补出。
- 结论不加限定词；推导依赖的条件写进前提。
- 区分最坏情形与一般情形，分别给出。

## 必答要素

- 结论。
- 前提清单，包含各变量的含义与取值范围。
- 推导步骤，读者可逐步复核。
- 取等条件与边界情形。
- 复杂度类结论同时给时间与空间，并说明主导项来自哪一段。

## 验收

- 每一步都能指出依据。
- 变量先定义后使用。
- 没有读者无法复核的跳步。
- 边界情形已给出。
