# 场景：因果机制

## 判断

用户问某个现象为什么出现、某个改动为什么有效、某个改动带来了什么。命题已被接受，只问原因。

## 方法

- 按"原因、中间环节、结果"写出机制链，每一环有依据。
- 写明机制起作用所需的背景条件，区分必要条件与充分条件。
- 改动类：先说改动前后哪里不同，再说差异影响了整体的哪一部分、占多大比重。
- 同时交代没有改变的部分，使读者知道改动的边界。

## 必答要素

- 现象（已接受的命题）。
- 机制链。
- 起作用的条件，以及不起作用的情形。
- 改动类追加：改变了什么、没有改变什么、收益来自哪一部分、代价（复杂度、可读性、正确性风险）、时间与空间复杂度的变化。

## 验收

- 机制链每一环有依据，没有靠"因此""所以"硬连的环节。
- 条件与例外只写会改变读者决定的。
- 收益有量级或明确的来源。
- 未把相关当作因果。
