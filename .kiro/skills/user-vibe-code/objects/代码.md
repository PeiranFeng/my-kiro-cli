# 对象：代码

一份代码改动：自己写的，或他人（AI）写的，形式为本地改动、提交范围或分支与基线的差异。

## 列出

从 diff 列出：

1. 改动的文件、函数、类。
2. 新增或改动的每个 guard：校验、try/except、默认值、兜底分支、类型转换、空值处理。
3. 新增或改动的每一处跨模块调用与依赖，每个构造入口，每份格式的读写处。
4. 消费的数据与调用的外部接口。
5. 行为变化。

## 读代码

读每处改动的周边代码与被消费数据的生产方。读取范围限于 diff 涉及的文件与必要的类型实现。

## 打分

对上面列出的每一项，按 `checklist.md` 的一、三逐项打分；改动含测试代码时，测试部分按 `objects/测试.md`。
