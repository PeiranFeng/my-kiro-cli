# AI 开发原则库

记录从实际开发案例中归纳出的、适配于自定义开发的原则，由 `interfaces/analysis.md` 追加。案例本身不记在这里，只记归纳后的原则；文献与公开实践里的已知形态见 `principles/ai-failure-patterns.md`。条目只追加；修订已有条目记录更正日期与原因。积累到可以归纳时，由 analysis 提出整理进 `principles/` 的建议，经用户确认后修改。

## 条目格式

- 标题：一句话概括该原则。
- 原则：适用于自定义开发的规则，一句话。
- 问题形态：它防止的 AI 行为，不含具体案例。
- 适用情形与边界。
- 检出方法：review 时用什么问题或检查发现违反。
- 与 `principles/` 的关系：已覆盖、需补充，或缺哪一条。
- 验证情况：用户确认或实验记录。
- 记录日期。
